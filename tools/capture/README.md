# Plate capture

A Playwright harness run against the production build (real Chrome with the GPU, WebGPU).

- `npm run capture` builds the site, then runs `tests/plates.spec.ts` and `tests/labels.spec.ts`:
  - **Static fallback figures** (`apps/site/public/plates/<id>.png`), captured centred in capture mode.
  - **Determinism:** cold load vs forward and backward scroll arrival at every plateau (< 0.5% of pixels).
  - **Focus and announcements:**
    - passive scrolling never moves focus or announces transitions;
    - J/K focuses the settled heading.
  - **Reduced motion:** only whole-plate states are rendered (dissolves).
  - **Static tier (`?static`):** every plate has its figure and description.
  - **Labels:** landscape and portrait, at Clinical depth.
    - count limits (6 / 4);
    - no overlap; inside the scene;
    - text >= 4.5:1 and leaders >= 3:1 against the rendered pixels;
    - focus structures >= 15 L* above the field.
- `npm run perf` measures and reports; it is not a check. It writes `docs/perf/m1-report.json` (`tests/perf.spec.ts`):
  - frame pacing on High (1600x1000 and a 2560x1440 canvas);
  - Mid on WebGL2 with the CPU throttled 4x;
  - cold-load payload and time to interactive on 50 Mbps.
- `node tools/capture/firefox.mjs` (after `npm run build`) drives stock Firefox over WebDriver BiDi. Playwright's Firefox is a separate patched build, so it is not used. The script records every plate's backend, tier, labels and console errors to `output/firefox/report.json` (copied to `docs/perf/firefox-m1.json`).

Output goes to `output/` (gitignored). The clinical review packet is generated by `npm run review` (tools/validate/src/review.ts).
