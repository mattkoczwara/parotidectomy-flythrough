# Source manifests

One manifest per third-party dataset: URL, version, sha256, licence, attribution text, date retrieved. Raw downloads go in `raw/` (gitignored), and each needs user approval before downloading.

Candidates (plan §7):
- Human Reference Atlas (CC BY 4.0);
- Visible Human Project CT and cryosections (NLM attribution);
- TotalSegmentator weights (Apache-2.0; cite its papers);
- MPFB/MakeHuman base head (CC0 output).
